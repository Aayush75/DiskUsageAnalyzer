# Changelog

## 0.1.0 — Initial Windows implementation

- Native WPF desktop app with dark/light/high-contrast styling, folder/drive selection, usage cards, linked exploration/map, file-type breakdown, filters and paged lists.
- Disk-backed SQLite scan index, cancellation/partial coverage, long-path metadata, and conservative cleanup eligibility.
- Explainable temp, .NET output, JavaScript dependency, Python environment and pip-cache findings.
- Opt-in streaming SHA-256 plus byte-verified duplicate groups with retained keeper protection.
- Exact review manifests, mandatory Cancel-default confirmation, acknowledged approval, expiring single-use authorization, identity-bound native operations and sequential outcomes.
- Default local recovery folders, non-overwriting restore, separately confirmed permanent deletion and recovery-file removal; no Windows Recycle Bin claim or auto-purge.
- Unit/property-style and real NTFS tests, production-window WPF workflow assertions, coverage and scalability harnesses, pinned dependency locks, Windows CI, self-contained packaging and installer source.

Known limitations and unverified release environments are listed in `docs/VALIDATION.md` and `docs/RELEASE.md`. No GitHub release has been published yet.
